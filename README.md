# seshat

Scriptlet resources for content blocking, built automatically from public sources and signed.

| File | What it is |
|---|---|
| `recursos.json` | The resources (version 6) |
| `recursos.json.sig` | ECDSA P-256 / SHA-256 signature of `recursos.json` (Base64 DER) |
| `version.json` | Version, SHA-256 and sources |
